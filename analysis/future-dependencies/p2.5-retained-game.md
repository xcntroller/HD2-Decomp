## Entry: active game → retained menu

Controller006C20F0 consumes status14 only if current type is1. In offline mode
`flags&7==7`, first copy game+64 into controller+20 BYTE, then call

3. Set returned state's status1. Call game+58 receiver0049B7C0(1), then camera

getter null during initialization. No game shutdown,
destructor, loader, actor clone or ownership transfer is called here.

**Allocation failure is not rollback:**0069E620 returns the original game,

sound-frame changes did occur. Original can leave the current game paused with
camera input disabled. A reconstructed failure recovery may restore the saved

## Failure, shutdown and remaining limits

Original common initialization ignores derived hook results in this path;
0069E620 does not test an initialization result.0067FB00 skips failed model
loads, appends only successful screen initialization and finally requests screen1
(or conditional3). Missing required screens are not a successful empty menu.
Several allocation branches dereference null; there is no established atomic
acquire/rollback protocol. Native checked-prefix cleanup is a deviation, not an
original guarantee. No recoverable original input-context setup failure is
established: shared engine/device ownership survives.

Normal15/16/11 borrowed-pointer lifetimes are closed. **Direct application
shutdown while current type11 is a separate policy boundary:**006C0920 invokes
only current+08 and current deleting destructor (unless reinitialize), then
closes mouse. Neither it nor verified0067F460/0067F1A0 retires5B8's game.
Do not claim the original safely destroys both owners here. The native controller
must keep exclusive ownership of its retained game and explicitly shut it down
after menu borrowers are retired, before controller caches/devices/world services
are released. That defensive lifetime policy extends the verified original path.
Status4 already present on entry to006C20F0 returns false; a4 produced during
update follows its shutdown case, so host final teardown must be idempotent.

Remaining research limits are conditional player/session internals, deep existing
effect/model services and foreign engine failure behavior. They do
not block the bounded offline retain/resume contract. Native shutdown deviation
needs explicit implementation review and focused failure tests. Actual P2.3
owners, source integration and every desktop case remain delivery prerequisites.
