not accept gameplay. Use the established reconstructed launcher
`python3 -B tools/run_application_launch.py` with the legitimate accessible
mission/profile and accepted P2.3 build. Never run the original commercial client
as a test oracle. Record compiled build SHA, main source SHA, mission/resource,
profile/mode and case outcome. Keep assets/profile contents outside Git.

log stable actual game/scene/selected Human identities and loader/spawn/shutdown
counts, and provide temporary focused diagnostics for pause64/clocks/module ticks
